Seção 1

O que é um Prompt? 💬

Um prompt é simplesmente a instrução que você dá para a IA. É o texto de entrada que define o que você quer que ela faça, como quer que ela responda e qual contexto ela deve considerar.

🧑‍💼
Pense assim: a IA é um estagiário extremamente inteligente, mas muito literal. Ele faz exatamente o que você pede — nem mais, nem menos. Se você pede "escreve um código", ele vai escrever qualquer coisa. Se você pede "escreve uma função Python que valida email e retorna booleano", ele entrega exatamente isso.

A qualidade do seu prompt determina diretamente a qualidade da resposta.

Seção 2

Técnicas de Prompt Engineering 🛠️

Diferentes situações pedem técnicas diferentes. Aqui estão as quatro mais usadas no dia a dia do desenvolvimento.

⚡
Zero-shot — Perguntar direto
Você pede algo sem dar nenhum exemplo. Funciona bem para tarefas simples e bem definidas.
📝 Prompt zero-shot Classifique o sentimento deste review como Positivo, Negativo ou Neutro:
"O produto chegou rápido mas a embalagem estava amassada."
🤖 Resposta da IA Neutro — O review menciona um ponto positivo (entrega rápida) e um negativo (embalagem danificada), sem predominância de nenhum dos dois.
💡 Quando usar: Tarefas únicas, classificações simples, perguntas diretas onde o modelo já tem contexto suficiente.
🎯
Few-shot — Dar exemplos antes de pedir
Você fornece 2–5 exemplos do padrão que quer antes de fazer o pedido real. Melhora consistência dramaticamente.
🎮 Exercício interativo: Arraste os exemplos para o prompt e veja a qualidade da resposta melhorar!

Chain-of-Thought — Pense passo a passo
Pedir que a IA raciocine explicitamente antes de responder. Reduz erros em problemas complexos de lógica e matemática.
🎮 Exercício: Ative o "Pense passo a passo" e veja a diferença no resultado!
Modo do prompt:
📝 Problema Um array começa com 128 elementos. A cada iteração, você remove metade.
Após quantas iterações o array terá menos de 10 elementos?

💭 Pense passo a passo antes de responder.
🤖 Resposta sem CoT ❌ A resposta é 3 iterações.
(Errado — o modelo chutou sem calcular)
🧠 Raciocínio da IA
1
Início: 128 elementos
2
Iteração 1: 128 ÷ 2 = 64 elementos
3
Iteração 2: 64 ÷ 2 = 32 elementos
4
Iteração 3: 32 ÷ 2 = 16 elementos
5
Iteração 4: 16 ÷ 2 = 8 elementos → menor que 10! ✓
🤖 Resposta com CoT ✅ Após 4 iterações, o array terá 8 elementos — menos que 10.

Seção 4

Erros Comuns — Anti-patterns ⚠️

Clique nos cards para revelar o problema e a correção. Reconhecer esses padrões vai te salvar de muita frustração com a IA.

❌ Anti-pattern #1
Prompt muito vago
"Melhora meu código" — sem contexto, sem critério, sem objetivo claro.
✅ A correção
Seja específico e contextual
"Refatore essa função para reduzir complexidade ciclomática e adicionar tratamento de erro para array null ou vazio."
❌ Anti-pattern #2
Instruções contraditórias
"Seja breve mas explique tudo detalhadamente" — a IA não sabe o que priorizar.
✅ A correção
Priorize claramente
"Responda em no máximo 3 linhas. Se precisar de mais, use bullet points." — limite claro + estrutura definida.
❌ Anti-pattern #3
Contexto demais (token waste)
Colar 500 linhas de código só para perguntar sobre 3 linhas específicas.
✅ A correção
Inclua só o relevante
Extraia só a função problemática. Descreva o resto em texto. Menos tokens = resposta mais precisa e mais barata.
❌ Anti-pattern #4
Não definir formato de saída
"Liste os erros do código" — pode voltar prosa, tabela, JSON, qualquer coisa.
✅ A correção
Especifique o formato
"Retorne array JSON: [{linha, severidade, descricao, sugestao}]" — saída previsível = integração simples.
