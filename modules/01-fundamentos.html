Fundamentos de IA Generativa

Entenda de vez o que é IA, como LLMs funcionam e por que tokens, temperatura e probabilidade importam para você como dev.

1

O que é Inteligência Artificial?

Definição simples: IA é software que aprende padrões a partir de dados em vez de seguir regras escritas manualmente.

Pense num sistema que identifica spam. Você poderia escrever milhares de regras — "se tiver 'ganhe dinheiro' → spam". Mas spammers mudam. A solução moderna: mostrar ao sistema milhões de exemplos de spam e não-spam, e deixá-lo descobrir os padrões sozinho.

🔑 A virada histórica: antes, humanos programavam regras explícitas. Com Machine Learning, humanos fornecem dados e o algoritmo deriva as regras. O desenvolvedor passa a ser curador de dados, não escritor de regras.

O que é um LLM?

LLM (Large Language Model) é um modelo treinado em quantidades gigantescas de texto — livros, artigos, código, sites — para aprender a prever qual palavra (token) vem a seguir.

Simples assim. O GPT-4, o Claude, o Gemini são todos, no fundo, máquinas de completar texto extremamente sofisticadas. Eles não "pensam" — eles calculam probabilidades.

🧮 Analogia do dev: pense no LLM como uma função f(contexto) → próximo_token. Rodando isso em loop, o modelo gera texto. O que parece "raciocínio" é na verdade bilhões de parâmetros ajustados para produzir saídas úteis.

⚡ Implicação prática: o LLM não tem certezas. Ele tem probabilidades. Por isso pode "alucinar" — gerar algo plausível mas errado. Entender isso muda como você usa IA no seu código: sempre valide saídas críticas.

Tokens — A linguagem da IA

O modelo não lê palavras — lê tokens. Um token é um pedaço de texto: às vezes uma palavra inteira, às vezes parte de uma palavra, às vezes pontuação.

Regra prática: em inglês, ~1 palavra ≈ 1–1.3 tokens. Em português, palavras mais longas = mais tokens. Emojis = 1–3 tokens cada.

Tokens importam porque os modelos têm um limite de contexto (janela de tokens). Ultrapassar esse limite = o modelo "esquece" o início da conversa.

Temperature e Criatividade

Temperature é um parâmetro que controla o quão "ousado" o modelo é ao escolher o próximo token.

Com temperature 0, o modelo sempre escolhe o token mais provável — respostas previsíveis e repetíveis. Com temperature 1+, escolhas menos prováveis ganham mais chance — respostas criativas, mas potencialmente incoerentes.

👨‍💻 Dica de uso: para código e dados estruturados, use temperature: 0. Para brainstorm e copywriting, use temperature: 0.7–1.0. Acima de 1 → território experimental.

Quiz Final — Módulo 1

5 perguntas para consolidar o que você aprendeu. Cada questão dá feedback imediato.

Questão 1 / 5
Qual a principal diferença entre programação tradicional e Machine Learning?
✅ Exato! Em programação tradicional, você escreve regras explícitas. Em ML, você fornece dados de entrada e saída esperada, e o algoritmo deriva as regras automaticamente.
Questão 2 / 5
O que um LLM faz fundamentalmente ao gerar texto?
✅ Correto! LLMs são, no fundo, máquinas de prever o próximo token. O texto coerente que emerge é resultado de bilhões de parâmetros ajustados para tornar previsões úteis e fluentes.
Questão 3 / 5
Por que LLMs podem "alucinar" (gerar informações falsas)?
✅ Isso mesmo! O modelo maximiza probabilidade, não veracidade. Texto plausível e texto verdadeiro são coisas diferentes. Por isso outputs críticos devem ser validados.
Questão 4 / 5
Qual configuração de temperature você usaria para gerar código SQL que precisa ser preciso e repetível?
✅ Perfeito! Para tarefas que exigem precisão e reprodutibilidade — código, SQL, JSON — temperature 0 é a escolha certa. Temperature alta introduz variabilidade indesejada em contextos técnicos.
Questão 5 / 5
Um texto de 1000 palavras em português tem aproximadamente quantos tokens?
✅ Isso mesmo! Em português, palavras mais longas e sufixos verbais fazem com que o número de tokens seja tipicamente 30–70% maior que o de palavras. Importante calcular ao estimar custos de API.
