Módulo 05

RAG & Tools
Dando Memória e Ferramentas à IA

Como fazer a IA responder sobre seus dados, acessar APIs em tempo real e executar ações no mundo real.

Seção 1

O Problema — IA Não Sabe Tudo

LLMs foram treinados em dados públicos com uma data de corte. Eles não têm acesso ao que aconteceu depois, nem a dados que nunca foram publicados na internet.

📅
Data de corte

GPT-4o, Claude, Gemini — todos têm uma data após a qual não sabem nada.

🔒
Dados privados

Manual da sua empresa, código do repositório, tickets do Jira — nunca vistos pelo modelo.

🌀
Alucinação

Quando não sabe, o modelo pode inventar uma resposta convincente mas completamente errada.

Alucinação não é bug, é característica do design. O modelo sempre tenta gerar o token mais provável — mesmo sem informação suficiente. RAG e tools são as soluções para isso.

Seção 2

RAG — Retrieval-Augmented Generation

RAG é a técnica de buscar documentos relevantes e injetá-los no contexto do modelo antes de responder. O modelo não é re-treinado — ele simplesmente recebe mais informação no prompt.

1

Indexar — Criar os Embeddings

Cada documento da sua base de conhecimento é convertido em um vetor numérico. Documentos com significado similar ficam "próximos" nesse espaço vetorial.

"Nosso suporte funciona 24h" → [0.23, -0.45, 0.89, 0.12, -0.67, 0.34, ...]
"Horário de atendimento ao cliente" → [0.21, -0.43, 0.91, 0.10, -0.65, 0.38, ...]
📚 Analogia: como criar o índice no final de um livro — mas com matemática. Em vez de páginas, são posições em espaço multidimensional.
2

Buscar — Encontrar Documentos Relevantes

A pergunta do usuário também é convertida em embedding. O sistema busca os documentos matematicamente mais próximos da pergunta.

🔍 Analogia: como uma busca no Google, mas para seus documentos privados — e baseada em significado, não em palavras-chave exatas.
3

Injetar — Montar o Contexto

Os documentos mais relevantes são inseridos no prompt antes da pergunta. O modelo recebe tudo junto na janela de contexto.

[SYSTEM] Use apenas os documentos abaixo para responder.
[DOC 1] Nosso suporte funciona 24h via chat no site...
[DOC 2] Para resetar senha, acesse configurações > segurança...
[USER] Como faço para resetar minha senha?
4

Responder — Com Base nos Documentos

O modelo gera a resposta baseado nos documentos fornecidos. Se os documentos têm a informação correta, a resposta será correta — e pode citar a fonte.

Com RAG você mantém a base de conhecimento atualizada e o modelo responde com precisão, sem retreinar.

Seção 3

Embeddings — Significado em Números

Um embedding transforma palavras ou frases em pontos num espaço matemático. Palavras com significado similar ficam próximas. O modelo aprende essas posições durante o treinamento.

Isso é fundamental para o RAG: quando buscamos documentos relevantes, estamos calculando quais pontos estão mais próximos da pergunta nesse espaço.

Visualização 2D (simplificada) — clique em qualquer palavra
Clique em uma palavra para ver os vizinhos mais próximos

Atenção: Na realidade, embeddings têm centenas ou milhares de dimensões. A visualização 2D é uma simplificação para intuição — não representa as distâncias exatas.

Seção 4

Tools & MCP — As Mãos da IA

RAG dá memória à IA. Tools dão ação. Com tools, o modelo pode consultar APIs, executar código, enviar mensagens, criar tickets.

MCP (Model Context Protocol) é o padrão universal criado pela Anthropic para conectar ferramentas a qualquer modelo de IA.

🔌
Antes do USB

Cada dispositivo tinha seu próprio conector. Impressora, câmera, mouse — todos diferentes. Caos.

🔗
Depois do USB

Um padrão. Qualquer dispositivo, qualquer computador. Plug-and-play.

🤖
Antes do MCP

Cada integração de IA era customizada. GitHub, Slack, banco de dados — código diferente para cada um.

⚡
Com MCP

Um protocolo. Qualquer ferramenta, qualquer modelo. Conecte uma vez, funciona em todo lugar.

🤖 Modelo de IAGPT-4, Claude, Gemini...
↓ MCP Protocol ↓
🗄️ Banco de Dados
🌐 APIs Externas
📁 Sistema de Arquivos
💬 Slack / Teams
🐙 GitHub
🔍 RAG / Busca
📧 Email
🎫 Jira / Linear

Cada caixa é um MCP Server — um processo separado que expõe tools via protocolo padronizado.

São abordagens complementares, não concorrentes. A chave é entender o que cada uma resolve melhor.
