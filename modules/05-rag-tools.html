Seção 1 / 7

O Problema — IA Não Sabe Tudo

LLMs são treinados em dados históricos. Eles não conhecem seus dados privados nem eventos recentes.

Linha do Tempo do Conhecimento

📚
Dados de treino
toda internet até X
🤖
Modelo treinado
conhecimento "congelado"
❓
Dados novos
o modelo não sabe
🔒
Seus dados privados
nunca vistos

Três formas de resolver:

Opção 1

Fine-tuning

Re-treinar o modelo com seus dados. Permanente, mas caro e lento. Não é ideal para dados que mudam.

Opção 2

Context Stuffing

Colocar todos os dados no prompt. Simples, mas limitado pela janela de contexto e caro em tokens.

✅ Melhor
Opção 3

RAG

Buscar somente o relevante sob demanda. Escalável, atualizado, e custo-eficiente.

💡

Por que RAG é o melhor dos dois mundos?

Combina o poder do LLM (raciocínio, linguagem) com seus dados reais (atuais, privados). Você não treina de novo — você dá o contexto certo na hora certa.

Seção 2 / 7

RAG — Retrieval-Augmented Generation

Como o modelo "consulta" seus documentos antes de responder.

1

Indexação — transformar documentos em vetores

Cada documento é convertido em um "embedding" — um vetor numérico que captura seu significado. Esses vetores ficam armazenados num vector store (banco de vetores).

📄 Doc 1
→
✨ Embedding
→
[0.23, 0.87, −0.41, …]
2

Busca — encontrar os documentos mais próximos

Quando o usuário faz uma pergunta, ela também vira um vetor. O sistema encontra os documentos cujos vetores são mais próximos no espaço semântico (busca por similaridade de cosseno).

❓ Pergunta
→
Vetor da query
→
🔍 Top 3 docs similares
3

Geração — resposta baseada nos documentos relevantes

Os documentos encontrados são injetados no contexto do LLM junto com a pergunta. O modelo responde baseado nesses documentos — não em memória genérica.

❓ Pergunta
→

Embeddings — A Magia por Trás

Como texto vira números — e por que isso captura significado.

🧠

Embeddings transformam texto em números que capturam SIGNIFICADO

Palavras ou frases semanticamente próximas ficam matematicamente próximas no espaço vetorial. Isso permite busca por sentido, não apenas por palavras-chave.

Aritmética de Palavras

rei
−
homem
+
mulher
≈
rainha
↓

Os vetores capturam relações semânticas. Não é coincidência — é geometria do significado.

🔬 Calculadora de Similaridade Semântica

Digite duas frases e veja o quão semanticamente similares elas são (baseado em sobreposição de palavras-chave como heurística simplificada).

—
Similaridade semântica

* Heurística simplificada usando sobreposição de termos. Embeddings reais usam redes neurais para captar nuances muito mais sutis.

📐 Alta Similaridade

"Cancelar assinatura"
"Encerrar meu plano"
"Quero parar de pagar"

Intenções parecidas → vetores próximos → RAG encontra o documento certo

📏 Baixa Similaridade

"Cancelar assinatura"
"Receita de bolo de cenoura"

Intenções opostas → vetores distantes → RAG não confunde os documentos

Como funciona — passo a passo

👤
Usuário pergunta: "Qual o faturamento de março?"
🤖
IA decide: "Preciso consultar o banco de dados para responder isso."
📝
IA gera: query_database("SELECT SUM(revenue) FROM sales WHERE month = 3")
⚙️
Sistema executa a query e retorna: {"result": 150000}
💬
IA formata: "O faturamento de março foi R$ 150.000."
Passo 1 / 5
⚠️

A IA não EXECUTA a tool — ela PEDE para o sistema executar

O modelo gera uma chamada estruturada (JSON). Seu sistema valida, executa, e devolve o resultado. Isso mantém segurança e controle — a IA nunca tem acesso direto ao banco.

Seção 5 / 7

MCP — Model Context Protocol

O padrão universal para conectar tools à IA. Pense nele como um "USB para modelos de linguagem".

🔌

USB

Padrão universal para conectar periféricos (teclado, mouse, HD) ao computador. Um conector, infinitos dispositivos.

≈
🤖

MCP

Padrão universal para conectar tools (banco, Slack, GitHub) à IA. Um protocolo, qualquer modelo compatível.

Ferramentas conectadas via MCP
💬
Slack
→ MCP
🐙
GitHub
→ MCP
🗄️
Banco de Dados
→ MCP
📝
Notion
→ MCP
🔌
↓
🤖 Qualquer LLM compatível com MCP
⚡
Uma vez implementado

Funciona com qualquer modelo compatível. Não precisa reimplementar por modelo.

📐
Padronização

Não precisa reinventar a roda. A comunidade já criou tools para os serviços mais comuns.

🔒
Segurança centralizada

Controle de permissões em um único ponto. Cada tool declara o que pode e o que não pode fazer.
