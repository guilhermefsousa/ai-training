Seção 01

Assistentes de Código

Seu copiloto diário. Essas ferramentas escrevem, editam e debatem código com você — cada uma com uma filosofia diferente.

🐙

GitHub Copilot

Autocomplete inteligente direto no editor. Sugere linhas e funções inteiras enquanto você digita. Funciona com VS Code, JetBrains e Neovim.
~$10/mes Autocomplete
🧠

Claude Code

Agente autônomo que lê, edita, testa e comita código. Opera no terminal e IDE. Pode executar bash, git, rodar testes e fazer refactors completos.
Pay-per-use Agente completo
✨

Cursor

VS Code turbinado com IA nativa. Chat integrado + autocomplete + "Composer" que edita múltiplos arquivos de uma vez seguindo instruções.
Free + $20/mes Pro IDE com IA
🌊

Windsurf

IDE com IA nativa e agente "Cascade" que planeja e executa tarefas multi-step. Alternativa com bom free tier.
Free tier generoso IDE + Agente
⌨️

Aider

CLI open source para pair programming com IA. Integração git nativa, suporta múltiplos modelos (Claude, GPT, Llama, etc.).
Gratis (OSS) Terminal

    Seção 04

    Modelos & APIs — O Cardápio

    Cada modelo tem forças diferentes. Escolher o certo é como escolher a ferramenta certa pra cada tarefa.

    ModeloEmpresaMelhor paraPreco (input/1M)Context
    Claude Opus 4AnthropicRaciocínio complexo, código, agentes~$15200K
    Claude Sonnet 4AnthropicMelhor custo-benefício geral~$3200K
    GPT-4oOpenAIMultimodal, velocidade~$2.50128K
    GPT-o3OpenAIRaciocínio avançado~$10200K
    Gemini 2.5 ProGoogleContexto gigante, multimodal~$1.251M+
    Llama 4MetaOpen source, self-hostedGratis*128K
    DeepSeek V3DeepSeekCusto muito baixo, código~$0.27128K
    Mistral LargeMistralEuropa, multilingual~$2128K

    * Self-hosted = custo de infra. Precos aproximados, podem variar.

    Escolha o Modelo Certo
    1. Startup com pouco budget precisa de um coding assistant bom e barato.
    DeepSeek V3 ($0.27/M) ou Claude Sonnet ($3/M) são os melhores custo-benefício para código. DeepSeek é imbatível em preço, Sonnet é mais versátil.
    2. Empresa precisa processar 500 páginas de contrato de uma vez.
    500 páginas ≈ 250K+ tokens. Só o Gemini 2.5 Pro com 1M+ de contexto consegue processar tudo de uma vez sem precisar dividir.
    3. App que precisa analisar imagens de produtos enviadas por clientes.
    GPT-4o e Gemini são os líderes em capacidade multimodal (texto + imagem). Ambos conseguem analisar imagens com alta qualidade.
    4. Dados sensíveis que não podem sair da empresa sob nenhuma hipótese.
    Llama 4 pode ser hospedado nos seus próprios servidores. Dados nunca saem da sua infra. É a única opção onde você tem controle total.

    Eval & Observabilidade

    Como saber se sua IA está funcionando? Existem ferramentas específicas para isso — você vai aprender em detalhes no próximo módulo. Aqui, um preview rápido:

    🧪 Promptfoo

    Open Source · CLI
    Testa prompts com datasets automatizados. O "unit test" dos seus prompts.

    📈 Langfuse

    Open Source · Analytics
    Tracing e analytics — veja custo, latência e qualidade de cada chamada.

    Proxy · Observabilidade
    Proxy simples que loga todas as chamadas de API com uma linha de código.
